Fantasy Oregon Trail Project Plan

Stephanie Monfredi

WDD 131.01

Overview

Purpose

Make a fun game that is kinda like Oregon Trail but it rage baits more and it is in a fantasy setting. Players can see how their decisions effect the story.

Audience

The audience would be kids, teens, and young adults who enjoy fantasy adventures, exploration, and decision-based games.

Dynamic elements

The game will use JavaScript to create an interactive adventure where players make choices that affect their journey. JavaScript will update the player's stats, display new story events, and determine the consequences of their choices. Conditional statements will determine different outcomes, and players will either successfully reach their destination or fail based on their decisions

Pseudocode for your project

Display welcome screen Display game instructions Ask player to choose a character Set player's starting health Set player's starting progress WHILE player has health AND has not reached destination Display current player stats Select a random encounter Display encounter story Display available choices WAIT for player to select a choice IF player chooses option 1 Apply consequences of option 1 ELSE IF player chooses option 2 Apply consequences of option 2 ELSE Apply consequences of option 3 END IF Update player health Increase journey progress IF player runs out of food Decrease player health END IF IF player health reaches zero Display game over screen END IF END WHILE IF player reaches destination Display victory screen ELSE Display game over screen END IF END GAME
